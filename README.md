# Do You Know Ethiopian History?

This is a simple command-line quiz game built in Python that tests your knowledge of Ethiopian history. 

## Features
- A 10-question multiple-choice quiz covering various periods of Ethiopian history, from the Aksumite Empire to the medieval Zagwe and Solomonic dynasties.
- Interactive command-line prompts to record user answers.
- Automated scoring system that tallies correct answers.
- A summary at the end displaying your total score (out of 10) and providing the correct answers for any questions you missed.

## Requirements
- Python 3.x

## How to Play
1. Run the script in your terminal:
   ```bash
   python Do_You_Know_Ethiopian_History.py
   ```
2. The game will present a question along with four multiple-choice options (a, b, c, or d).
3. Type the letter corresponding to your answer and press `Enter`.
4. After answering all 10 questions, your final score and corrections for any wrong answers will be displayed.

## Skills Demonstrated
This project demonstrates the use of basic Python programming concepts, including:
- Loops (`for` loops)
- Dictionaries (key-value pairs for questions and answers)
- User input and string manipulation
- Comparisons and logical operators
- Counters and print formatting (f-strings)
